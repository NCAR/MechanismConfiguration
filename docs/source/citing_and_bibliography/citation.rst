
Citing Mechanism Configuration
==============================

If you use this software, please cite it. The ``CITATION.cff`` file in the repository has the
same information. GitHub also shows it in the "Cite this repository" menu.

Cite the software
-----------------

.. code-block:: console

  @software{ncar.acom.mechanism_configuration,
    author       = {Matthew Dawson and
                    Kyle Shores and
                    Jiwon Gim and
                    Montek Thind and
                    Scott Meech},
    title        = {Chemical Mechanism Configurations},
    publisher    = {Zenodo},
    doi          = {10.5281/zenodo.15116380},
    url          = {https://doi.org/10.5281/zenodo.15116380}
  }

The DOI above always points to the latest release. Zenodo also gives a DOI for each release.
